Appearance

Dark theme for SAS Studio's own interface, the Ace editor dark/light theme always follow OS darkmode setting. Applies to open SAS Studio tabs immediately.

  • Always on - always uses dark theme regardless of the OS setting
  • Follow system - follows OS darkmode setting
  • Off - uses SAS Studio default theme

Patches

Passive behavior changes, on by default. Applies on next page reload.

  • Log pane - switch to the Log pane when execution starts, and stay there when it finishes.
  • Keep focus - never change the focused pane automatically, at any point of the execution.
  • SAS Studio default - switch to the Log pane when execution starts, then to Results / Output Data (whichever was produced) when it finishes.

Both non-default options outline the tab of a pane that has new content instead of switching to it: Results and Output Data only, since the Log is written to throughout the execution. The outline blinks once per update and stays until you go to that pane.

Editor

Configuration for Ace editor in SAS Studio (code editor, text viewer). Also applies to the snippet editor below.

Aside from the settings below, every other settings is configured from Ace's own stock settings panel ("Ctrl-," in any editor, or the "Show settings menu" entry in the command palette when one is focused). Any change made there is persisted as the default for new editors and live-apply to open ones.
Note: setting of the snippet editor on this page is in sync with all Ace editors in all SAS Studio pages.

Vim Keymap

Applied to the Ace editors' vim keyboard handler (only takes effect once "Vim" is the active keyboard handler).

Syntax: One mapping per line, " starts a comment.

  • map/nmap/imap/vmap <lhs> <rhs>
  • noremap/nnoremap/inoremap/vnoremap <lhs> <rhs> (same, non-recursive)
  • unmap/nunmap/iunmap/vunmap <lhs>

Invalid syntax is skipped with a console warning. Removing a line here doesn't undo the mapping until the SAS Studio page is reloaded.

Custom ex-commands:

  • :w save, :w <path> save-as
  • :q close tab, :wq save & close
  • :x run the program/selection (like SAS Studio F3)
  • :marks list the marks that are set (they also show in the gutter)
  • ace provides :delmarks a / :delmarks a-z (the ! form isn't implemented)

To see every vim mapping (built-in ones included), run "Show vim key mappings" from the command palette.

Snippets

Native Ace snippet format (snippet trigger / tab-indented body), one set per language, additive over Ace's own built-in snippets for that language. The editor uses Ace's snippet-file mode for syntax highlighting; the language select chooses which language's snippet set is being edited. Text words and Ace's snippet-authoring templates are offered as you type and with Ctrl+Space. Definitions under the Snippets language are added to those templates when you switch away, and remain available whichever target language is selected. They remain marked unsaved until Save is clicked.

Switching language keeps whatever is in the box - the text follows the language you left it on and comes back when you return to it, and one Save writes every language at once. * in the list marks a language with unsaved edits, • one that has snippets saved. Undo history does not cross a language switch. Live-applies to open SAS Studio tabs on Save.
